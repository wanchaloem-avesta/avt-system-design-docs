# avt-system-design-docs

สกิลสำหรับ AI agent เช่น Claude Code ใช้สร้างชุดเอกสารออกแบบระบบจาก TOR ขอบเขตงาน หรือ requirement ก่อนเริ่มพัฒนา แล้วรีวิวว่าเอกสารถูกต้อง ไม่ขัดกัน และลำดับการทำงานครบ

ผลลัพธ์ที่ได้ในโฟลเดอร์โครงการ

```
├── README.md     ทางเข้า อธิบายระบบสั้น ๆ และควรเริ่มอ่านที่ไหน
├── docs/         เอกสารออกแบบ แยกไฟล์ตามหัวข้อ เช่น ภาพรวม ฟีเจอร์ Flow โครงสร้างข้อมูล API ประเด็นตัดสินใจ แผนพัฒนา
└── plans/        แผนงานขั้นถัดไป เช่น แผนทำ Mockup
```

## สิ่งที่ต้องมีก่อนติดตั้ง

| สิ่งที่ต้องมี | ใช้ทำอะไร | ตรวจด้วยคำสั่ง |
|---|---|---|
| Node.js (มาพร้อม `npx`) | ติดตั้งสกิลด้วย `npx skills` | `npx --version` |
| AI agent ที่รองรับสกิล เช่น Claude Code | ตัวที่รันสกิล | |
| Python 3 (ไม่บังคับ แต่ควรมี) | รันสคริปต์ตรวจเอกสารในขั้นรีวิว ถ้าไม่มี สกิลจะตรวจเองแทนและแจ้งในรายงาน | `python --version` หรือ `python3 --version` |

## ติดตั้ง

### ติดตั้งให้ใช้ได้ทุกโครงการ (แนะนำ)

```bash
npx skills add wanchaloem-avesta/avt-system-design-docs -g
```

`-g` คือติดตั้งระดับผู้ใช้ สำหรับ Claude Code สกิลจะอยู่ที่ `~/.claude/skills/`

### ติดตั้งเฉพาะโครงการเดียว

รันคำสั่งนี้ในโฟลเดอร์ของโครงการนั้น

```bash
npx skills add wanchaloem-avesta/avt-system-design-docs
```

สำหรับ Claude Code สกิลจะอยู่ที่ `.claude/skills/` ในโฟลเดอร์โครงการ

### ตัวเลือกที่ใช้บ่อย

| ตัวเลือก | ความหมาย | ตัวอย่าง |
|---|---|---|
| `-a <agent>` | ติดตั้งให้ agent ที่ระบุเท่านั้น ไม่ถาม | `-a claude-code` |
| `-y` | ข้ามคำถามยืนยัน | `-g -a claude-code -y` |
| `--copy` | คัดลอกไฟล์แทนการทำลิงก์ ใช้เมื่อเครื่องสร้างลิงก์ไม่ได้ เช่น Windows บางเครื่อง | `-g --copy` |
| `-l` | ดูรายชื่อสกิลใน repo โดยไม่ติดตั้ง | `npx skills add wanchaloem-avesta/avt-system-design-docs -l` |

ตัวอย่างติดตั้งให้ Claude Code ทุกโครงการโดยไม่ถาม

```bash
npx skills add wanchaloem-avesta/avt-system-design-docs -g -a claude-code -y
```

## ตรวจว่าติดตั้งแล้ว

```bash
npx skills list
```

ต้องเห็น `avt-system-design-docs` ในรายการ ถ้าเปิด Claude Code ค้างไว้ระหว่างติดตั้ง ให้เปิดใหม่หนึ่งครั้ง

## วิธีใช้

พิมพ์คุยกับ agent ตามปกติ สกิลจะทำงานเองเมื่อพูดถึง TOR ขอบเขตงาน requirement หรือเอกสารออกแบบระบบ หรือเรียกตรง ๆ ด้วย `/avt-system-design-docs` ใน Claude Code

ตัวอย่างคำสั่ง

- `ทำเอกสารออกแบบระบบจาก TOR ในโฟลเดอร์ D:\projects\helpdesk\tor`
- `ช่วยวิเคราะห์ระบบจากขอบเขตงานนี้ก่อนเริ่มพัฒนา` แล้ววางข้อความหรือแนบรูปผังงาน

ลำดับที่สกิลทำ

1. อ่านข้อมูลต้นทางให้ครบ รับได้ทั้งข้อความ ไฟล์ PDF Word Excel และรูป
2. สรุปความเข้าใจ แจ้งจุดที่ข้อกำหนดขัดกันหรือขาดหาย และถามพร้อมข้อเสนอ แล้วหยุดรอคำตอบ ตอบสั้น ๆ ว่า "ใช้ตามที่เสนอ" ได้
3. วางคำศัพท์ เลขหัวข้อ และรายการประเด็นตัดสินใจ
4. เขียนเอกสารทั้งชุด
5. รีวิวด้วยสคริปต์ตรวจและอ่านเนื้อหา แล้วรายงานว่าพบอะไร แก้อะไร และเหลืออะไรที่ต้องให้ลูกค้าตัดสินใจ

ระบบขนาดกลางใช้เวลาประมาณ 1 ชั่วโมงรวมการรีวิว

## อัปเดตและถอนการติดตั้ง

```bash
# อัปเดตเป็นเวอร์ชันล่าสุด
npx skills update avt-system-design-docs

# ถอนการติดตั้ง (ใส่ -g ถ้าติดตั้งแบบทุกโครงการ)
npx skills remove avt-system-design-docs -g
```

## ปัญหาที่พบบ่อย

| อาการ | วิธีแก้ |
|---|---|
| `npx` ไม่รู้จักคำสั่ง | ติดตั้ง Node.js จาก nodejs.org แล้วเปิดหน้าต่าง terminal ใหม่ |
| ติดตั้งแล้วแต่ agent ไม่เห็นสกิล | เปิด agent ใหม่ ตรวจด้วย `npx skills list` ว่าติดตั้งระดับเดียวกับที่ใช้งาน (`-g` หรือในโครงการ) |
| ติดตั้งบน Windows แล้วสร้างลิงก์ไม่ได้ | ติดตั้งใหม่โดยเพิ่ม `--copy` |
| สกิลแจ้งว่าไม่ได้รันสคริปต์ตรวจ | ติดตั้ง Python 3 สกิลจะรันสคริปต์เองในครั้งถัดไป |

```
scripts/replace_checked.py   สคริปต์แก้ข้อความหลายจุดหลายไฟล์แบบตรวจจำนวน
```
